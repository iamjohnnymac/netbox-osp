# netbox-osp — placeholder

This `0.0.1` release on PyPI is a **name reservation** for the upcoming
`netbox-osp` plugin: outside-plant fibre management for NetBox.

It is **not** a functional plugin. Installing it will not do anything
useful in NetBox.

## Coming soon (v0.1.0)

- OSP cables, tubes, strands (with TIA-598 auto-coloured fibre positions)
- Splice closures, splice trays, splices with measured loss
- Fibre links with computed loss budgets (strand + splice + connector)
- Full-screen Leaflet plant map with online + offline base layers and
  auto-fallback when public tile servers are unreachable
- GeoJSON route editor for cables, drag-to-edit for closures
- Plant-boundary trace tool

See <https://github.com/iamjohnnymac/netbox-osp> for the real source,
issues, and release timing.
